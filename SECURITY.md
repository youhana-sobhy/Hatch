# Security policy

Please do not open public issues for security problems. Use GitHub's
[private vulnerability reporting](https://github.com/youhana-sobhy/Hatch/security/advisories/new)
with a description, the affected version or commit, and steps to reproduce.

You can expect an acknowledgement within three working days. Fixes are released as a patch
version with an advisory once a fix is available.

The design goals and controls are described in [docs/security.md](docs/security.md).
